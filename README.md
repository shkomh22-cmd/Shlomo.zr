# התקציב המשפחתי - גרסה עצמאית

אפליקציה שמותקנת על מסך הבית בטלפון, עובדת גם בלי אינטרנט, ומסתנכרנת בין שני בני הזוג דרך Firebase (חינם לשימוש משפחתי).

## מה בתיקייה
- `index.html` - האפליקציה
- `config.js` - כאן מדביקים את הגדרות Firebase
- `manifest.webmanifest`, `sw.js`, `icon-*.png` - מה שמאפשר התקנה על מסך הבית ועבודה בלי אינטרנט
- `firestore.rules` - כללי אבטחה: רק שני המיילים שלכם מורשים
- `firebase.json` - הגדרת פריסה

## שלב 1: פרויקט Firebase (5 דקות)
1. נכנסים ל-https://console.firebase.google.com עם חשבון Google ולוחצים **Add project**. אפשר לבטל את Google Analytics.
2. בתוך הפרויקט: **Build > Firestore Database > Create database**. בוחרים מיקום קרוב (למשל `europe-west`) ומצב **production**.
3. **Build > Authentication > Get started > Sign-in method**: מפעילים (Enable) גם **Email/Password** וגם **Google**. ב-Google בוחרים מייל תמיכה ושומרים.

## שלב 2: חיבור האפליקציה
1. **Project settings (גלגל השיניים) > Your apps > </> (Web)**. נותנים שם ולוחצים Register.
2. מעתיקים את אובייקט `firebaseConfig` שמוצג, ומדביקים אותו ב-`config.js` במקום `null`:
   ```js
   window.FB_CONFIG = { apiKey: "...", authDomain: "...", projectId: "...", appId: "..." };
   ```
   (המפתח הזה אינו סוד. האבטחה נקבעת בכללים בשלב הבא.)

## שלב 3: כללי אבטחה
פותחים את `firestore.rules`, מחליפים את שתי הכתובות בכתובות המייל שלכם (שלך ושל אשתך, באותיות קטנות), ומדביקים את התוכן ב-**Firestore > Rules > Publish**. בלי זה אף אחד לא יוכל לקרוא או לכתוב.

## שלב 4: פריסה לאינטרנט
האפליקציה חייבת להיות על כתובת https. הדרך הפשוטה (Firebase Hosting, באותו פרויקט):
```
npm install -g firebase-tools
firebase login
firebase use --add     # בוחרים את הפרויקט שיצרתם
firebase deploy
```
בסוף מקבלים כתובת כמו `https://your-project.web.app`. מומלץ להישאר עם Firebase Hosting, כי ההתחברות עם Google עובדת בו בצורה יציבה ביותר, גם בטלפון.
אם בוחרים אחסון אחר (Netlify, GitHub Pages): ב-Firebase, **Authentication > Settings > Authorized domains**, מוסיפים את הדומיין שלכם.

## שלב 5: התקנה בטלפון
פותחים את הכתובת בדפדפן. באייפון: Safari > שיתוף > **הוספה למסך הבית**. באנדרואיד: Chrome > תפריט > **התקנת אפליקציה**. נכנסים עם Google, או נרשמים עם מייל וסיסמה (ראו הסבר למטה). אשתך עושה אותו דבר עם המייל שלה.

## העברת הנתונים מהגרסה שבתוך Claude
1. בגרסה הישנה: **הגדרות (⚙ למעלה) > גיבוי והעברה**. נשמר קובץ JSON.
2. בגרסה החדשה, אחרי שהתחברתם: **הגדרות > גיבוי והעברה > שחזור מגיבוי**, ובוחרים את הקובץ.
תמונות קבלה אינן נכללות בגיבוי. נתונים שהוזנו כבר במצב מקומי לפני ההתחברות עולים לענן אוטומטית בכניסה הראשונה.

## מגבלות ידועות
- ההתראות מופיעות רק כשפותחים את האפליקציה. התראות דחיפה לטלפון דורשות שלב נוסף (Cloud Functions ו-FCM) שלא נכלל כאן.
- כל מי שהמייל שלו ברשימה בכללי האבטחה רואה ועורך את כל הנתונים. אין הפרדה בין משתמשים.
- הכללים מוגדרים למשק בית אחד (`households/home`).

## הרשמה והתחברות
במסך הפתיחה יש טופס עם אימייל וסיסמה (לפחות 6 תווים), וגם כפתור התחברות עם Google.
- **הרשמה:** מזינים מייל וסיסמה ולוחצים "הרשמה". נשלח מייל אימות. לוחצים על הקישור שבו וחוזרים לאפליקציה ללחוץ "התחברות".
- **שכחתי סיסמה:** מזינים את המייל ולוחצים "שכחתי סיסמה". נשלח קישור לאיפוס.
- **התנתקות:** כפתור "התנתקות" מופיע בראש הדף אחרי ההתחברות.
- **הרשמה לבדה לא נותנת גישה לנתונים.** גם אחרי שנרשמים ומאמתים מייל, רואים נתונים רק אם הכתובת ברשימה ב-`firestore.rules`. כך זר לא יכול להירשם ולקרוא את התקציב שלכם. כדי לצרף אדם נוסף מוסיפים את המייל שלו לרשימה ומפרסמים את הכללים מחדש (Firestore > Rules > Publish).
- אימות המייל חובה, כי בלעדיו מישהו יכול להירשם עם כתובת של מישהו אחר.

## איפה בסיס הנתונים
- **הנתונים עצמם** נשמרים ב-**Cloud Firestore**, מסד נתונים של Google שרץ בפרויקט Firebase שלכם, בחשבון Google שלכם. את המיקום (למשל אירופה) בוחרים בשלב 1, ואי אפשר לשנות אותו אחר כך.
- **המבנה:** אוסף ראשי `households`, ובו מסמך `home`, ובתוכו אוספים: `tx` (תנועות), `rec` (קבועות ותשלומים), `goals`, `loans`, `est` (משוערות), `rcp` (תמונות קבלה) ומסמך `config/budgets` (תקציבים).
- **לראות ולערוך ידנית:** Firebase Console > Firestore Database > Data.
- **משתמשים וסיסמאות** נשמרים בנפרד, ב-Firebase Authentication (Build > Authentication > Users). הסיסמאות מוצפנות ואינן נגישות לאף אחד, כולל לכם.
- **עותק מקומי בכל מכשיר:** האפליקציה שומרת עותק בדפדפן כדי לעבוד גם בלי אינטרנט, ומסנכרנת כשהחיבור חוזר.
- **עלות:** לשימוש משפחתי רגיל מספיקה בדרך כלל המכסה החינמית של Firebase (תוכנית Spark). כדאי לוודא את המכסות העדכניות בקונסולה.
- **גיבוי:** הנתונים לא מגובים אוטומטית. מומלץ לייצא מדי פעם "גיבוי מלא" מלשונית תנועות.
- בגרסה שרצה בתוך Claude הנתונים נשמרים במסד הנתונים של הדף עצמו אצל Claude, ולא ב-Firebase.

## גיבוי בטלפון
- **גיבוי לקובץ:** בהגדרות (⚙ למעלה), "גיבוי והעברה", לוחצים "גיבוי לטלפון (שמירה לקובץ)". נפתח תפריט השיתוף של הטלפון. באייפון בוחרים "שמירה בקבצים", ובאנדרואיד Drive או "קבצים". זה הגיבוי האמיתי, והוא נשאר גם אם האפליקציה נמחקת.
- **תזכורת:** אם לא בוצע גיבוי לקובץ במשך 7 ימים, מופיעה התראה בלשונית סיכום.
- **נקודות גיבוי אוטומטיות:** פעם ביום נשמר עותק בתוך האפליקציה (7 ימים אחרונים). אפשר לשחזר ממנו מאותה חלונית. העותקים האלה נמחקים אם מנקים נתוני דפדפן או מסירים את האפליקציה, ולכן הם משלימים את הגיבוי לקובץ ואינם מחליפים אותו.
- **שחזור** מוסיף פריטים שנמחקו, ואינו מבטל שינויים בפריטים קיימים.

## מה חדש בגרסה זו
עריכת תנועות, חיפוש וסינון, כללי סיווג אוטומטי, הוספה מהירה (כפתור + ורשימת הוצאות חוזרות), חשבונות עם יתרה, חלוקה בין בני הזוג, פיצול הוצאה לקטגוריות, תחזית סוף חודש, דוח שנתי ונעילה בקוד.
- **נעילה בקוד** נשמרת במכשיר בלבד. אם שכחתם את הקוד, "שכחתי קוד" מוחק את הקוד ואת הנתונים השמורים באותו מכשיר (נתונים בענן נשמרים), ולכן כדאי לגבות לקובץ.
- **אוספי נתונים חדשים** ב-Firestore: `rules` (כללי סיווג) ו-`accts` (חשבונות). אין צורך לשנות את כללי האבטחה.

## עבודה בלי אינטרנט
- אחרי שהאפליקציה נפתחה פעם אחת עם חיבור, היא נפתחת גם בלי חיבור ועובדת מהעותק שבמכשיר.
- תנועות שמוסיפים או עורכים בלי חיבור נשמרות במכשיר ומסתנכרנות לענן ולבן/בת הזוג כשהחיבור חוזר. כשאין חיבור מופיעה למעלה הודעה על כך.
- ייבוא מאקסל ושחזור מגיבוי דורשים חיבור.
- אם שני בני הזוג משנים את אותה תנועה בלי חיבור, העדכון האחרון גובר.

## מכסות חינמיות של Firebase (תוכנית Spark, נבדקו באוקטובר 2026)
- Firestore: 1 GiB אחסון, 50,000 קריאות ו-20,000 כתיבות ביום. מספיק למשפחה רגילה.
- Authentication (מייל, סיסמה ו-Google): חינם. Hosting: 10 GB אחסון ו-360 MB העברה ביום.
- חריגה ממכסה לא מחייבת כסף בתוכנית Spark, אלא עוצרת את השירות עד סוף החודש. אין צורך בכרטיס אשראי.
- Cloud Storage של Firebase דורש כיום תוכנית בתשלום (Blaze). האפליקציה לא משתמשת בו: תמונות הקבלה נשמרות כמסמכים קטנים ב-Firestore.
- המכסות משתנות מדי פעם, ולכן כדאי לוודא בקונסולה (Usage and billing).

## ענן חלופי
- **Google Drive/Google One:** Google One הוא מנוי להגדלת שטח האחסון בחשבון Google ואינו שירות שאפליקציה מתחברת אליו. אפליקציה יכולה להשתמש ב-Google Drive API ולשמור קובץ גיבוי בכונן של כל משתמש (15 GB חינם בחשבון, משותפים עם Gmail ו-Photos). מתאים לגיבוי, לא לסנכרון בזמן אמת בין שני חשבונות. דורש הגדרת OAuth בפרויקט Google Cloud.
- **חלופות כמו Supabase או Cloudflare:** אפשריות, אך דורשות כתיבה מחדש של שכבת הנתונים. בדקו תנאי שימוש חינמי עדכניים לפני כן.

## גיבוי ל-Google Drive
האפליקציה שומרת קובץ גיבוי אחד ליום בתיקייה "התקציב המשפחתי - גיבויים" בכונן שלכם, ואפשר לשחזר ממנו. כל גיבוי דורש אישור קצר של Google (לחיצה), כי אפליקציית אינטרנט לא יכולה לגבות ברקע בלי להתחבר מחדש. כדי להפעיל:
1. ב-https://console.cloud.google.com בוחרים את אותו פרויקט של Firebase (הוא גם פרויקט Google Cloud).
2. **APIs & Services > Library:** מחפשים **Google Drive API** ולוחצים Enable.
3. **APIs & Services > OAuth consent screen:** מגדירים External, שם לאפליקציה ומייל תמיכה. ב-**Scopes** מוסיפים `.../auth/drive.file`. ב-**Test users** מוסיפים את שני המיילים שלכם. אפשר להשאיר במצב Testing.
4. **APIs & Services > Credentials > Create credentials > OAuth client ID > Web application.** ב-**Authorized JavaScript origins** מוסיפים את כתובת האפליקציה (למשל `https://your-project.web.app`).
5. מעתיקים את ה-Client ID ל-`config.js` במקום `null` ב-`GDRIVE_CLIENT_ID`, ומפרסמים מחדש (`firebase deploy`).
- בפעם הראשונה Google תציג אזהרה שהאפליקציה לא אומתה. זה צפוי באפליקציה אישית: "מתקדם" ואז "המשך".
- האפליקציה רואה רק קבצים שהיא עצמה יצרה בכונן (הרשאת `drive.file`), ולא את שאר הכונן.
- כדי שהגיבויים יהיו גם בטלפון: באפליקציית Google Drive בטלפון בוחרים את התיקייה ומסמנים "זמין במצב לא מקוון".

## תיקייה בטלפון
אפליקציית אינטרנט לא יכולה לשמור אוטומטית בתיקייה שבחרתם בטלפון. לפי המקורות שמצאתי, בחירת תיקייה בדפדפן אינה נתמכת באנדרואיד, ובאייפון גם לא. הדרך הקרובה ביותר:
- **"גיבוי לטלפון (שמירה לקובץ)"** בחלונית הגיבוי פותח את תפריט השיתוף. באייפון בוחרים "שמירה בקבצים" ואז את התיקייה, ובאנדרואיד בוחרים "שמירה במכשיר" או Drive. אתם בוחרים את התיקייה בכל פעם.
- כדי שהגיבוי ייכנס לתיקייה קבועה אוטומטית צריך אפליקציה מקורית (למשל עטיפת Capacitor לאנדרואיד), וזה שלב נפרד שדורש בנייה במחשב עם Android Studio.

## עמוד ההגדרות
כפתור ⚙ ליד בורר החודש פותח עמוד הגדרות עם: שיתוף (שיתוף האפליקציה וסיכום בוואטסאפ), ייצוא וייבוא (אקסל ו-CSV), גיבוי והעברה, גיבוי ל-Google Drive, כללי סיווג אוטומטי ונעילה בקוד.
